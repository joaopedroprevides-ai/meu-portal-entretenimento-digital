# 🎮 Meu Portal de Entretenimento Digital

Projeto desenvolvido como atividade da **Agenda 13 – CSS**, do Curso Técnico em Desenvolvimento de Sistemas.

## 📌 Sobre o projeto

O Meu Portal de Entretenimento Digital é uma página web criada para reunir conteúdos de diferentes áreas do entretenimento. O projeto foi desenvolvido utilizando HTML e CSS, com foco na organização, navegação e apresentação visual das informações.

## 🎯 Objetivo

Desenvolver uma página web com três seções principais, aplicando os conhecimentos adquiridos em Desenvolvimento Web.

## 📂 Seções do portal

### 🎬 Filmes e Séries
Espaço dedicado a filmes, séries, cinema e produções audiovisuais.

### 🎵 Música e Podcasts
Área destinada a músicas, artistas, playlists e podcasts.

### 🎮 Games e Tecnologia
Seção sobre jogos, videogames, computadores e novidades tecnológicas.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** estilização e organização visual.
- **Flexbox:** organização das seções lado a lado.
- **CSS Reset:** padronização dos estilos iniciais dos elementos.

## 📁 Estrutura dos arquivos

- `portal.html` — arquivo principal da página.
- `estilo.css` — arquivo responsável pela estilização.
- `reset.css` — arquivo utilizado para redefinir estilos padrão do navegador.

## ✨ Recursos aplicados

- Menu de navegação com links internos.
- Três seções de entretenimento.
- Imagens ilustrativas em cada seção.
- Utilização de CSS inline, interno e externo.
- Aplicação de classes e IDs.
- Organização com Flexbox.
- Adaptação do layout para telas menores.
- Comentários para organizar os estilos CSS.
